CSV format guide

The CSV file must include a header row with these columns:

Column Required Description Example
date Yes Transaction date in YYYY-MM-DD format 2026-10-15
amount Yes Positive number, max 2 decimal places 25.50
type Yes Either expense or income expense
description For expenses Description of the expense (optional) Groceries
category For expenses Existing expense category name (must match exactly) Food and dining
source For income Income source (e.g., Salary, Freelance) Salary
notes For income Optional notes about the income October salary

Duplicate handling: Rows matching existing transactions (same date, amount, type, and description/source) are skipped automatically. Rows with the same data within the import file are also deduplicated.

Categories: For expenses, the category must already exist in your account and be an expense-type category. The name must match exactly (case-sensitive).
