This is a schedule-based forecast, not a bank balance. It projects materialized planned occurrences from active recurring schedules. It does not add historical spending, subscription summaries, savings goals or net worth to expected cash flow.

The window includes the start date and each UTC calendar day through the selected horizon. No transaction is created, edited or paid by running a forecast.
